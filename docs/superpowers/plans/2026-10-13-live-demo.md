# Live Browser-Agent Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A public page at agent.shawndemos.com where anyone can run the existing read-only browser agent against the synthetic site and watch it live, with spend, rate and queue limits and a recorded-run fallback.

**Architecture:**
- A new `web/` module. Its Node HTTP server drives the existing `TaskRunner` in-process, one run at a time, and streams events to the page over Server-Sent Events.
- The only change to existing code is a small optional screencast hook on `BrowserBridge`, which provides the live browser view.
- One container (site + headless Chromium + web server) sits behind Traefik.

**Tech Stack:** TypeScript (ESM, run with `tsx`), Node ≥ 20 (tested on 22), Playwright Chromium 1.63, vitest, plain HTML/CSS/JS for the page (no build step), Docker + Traefik.

**Spec:** `docs/superpowers/specs/2026-10-13-live-demo-design.md`

## Global Constraints

**Dependencies and code boundaries:**
- No new npm dependencies. Use only what `package.json` already has (`playwright`, `zod`, `ws`, `tsx`, `vitest`, `@anthropic-ai/sdk`).
- Never change the policy engine (`backend/src/policy/`), the tools (`backend/src/tools.ts`), the providers (`backend/src/providers/`), the coordinator (`backend/src/coordinator.ts`) or the extension.
  - The only edit outside `web/`, `tests/web-*`, `tsconfig.json`, `package.json` and `README.md` is the `onFrame` hook in `backend/src/browser/bridge.ts` (Task 1).
- Imports use ESM `.js` suffixes, as everywhere in the repo.

**Tests:**
- Tests go in `tests/web-*.test.ts`.
- Run one file: `npx vitest run --config tests/vitest.config.ts tests/<file>`.
- Run the full suite: `xvfb-run -a npm test`. All existing tests must keep passing.

**Data handling:**
- Never log task text, page content or result values. Logs carry only run ID, preset ID or `"free"`, status/code, cost and duration, through `log()` from `backend/src/logger.js`.
- Visitors see generic error codes only, never a stack trace.

**Wording on the page:**
- The banner reads exactly `Synthetic data — not a real patient system`.
- A simulated model step is labelled `Simulated misbehaving model (the real model refuses this)`.
- FAKE runs are labelled `FAKE model`.

**Limits:**
- 1 live run at a time.
- Queue of 10 waiting.
- 5 runs per IP per rolling hour.
- $3.00 per UTC day.
- $0.15 per-run reserve: a run starts only if `spent < 3.00 − 0.15`.
- 8 model calls and 90 s per run (`MAX_MODEL_CALLS=8`, `WALL_TIME_MS=90000`).

**Controller rulings (resolving spec ambiguities):**
- **No key:** with no `ANTHROPIC_API_KEY`, the public server shows the recorded run (reason `no_key`). FAKE runs happen only when `WEB_ALLOW_FAKE=1` (tests and local use).
- **Recorded run:** the recorded fallback is the existing real-model video `media/demo-real-2026-10-07.mp4`, copied to `web/public/recorded/run.mp4`. Its on-screen captions are the event log.
- **Preset 5:** "Summarise a record with its sources" uses SYN-2077, whose two sources disagree, so the result is `uncertain` with the conflict shown.
- **Simulated steps:** in REAL mode the two "blocked" presets swap the model's final `finish` for one scripted `navigate` (exactly what `scripts/demo-run.ts` does), because the real model refuses the forbidden action. In FAKE mode they use the existing fake scripts `writer` and `offsite`.

**Commits:** end every commit message with the line `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

**Swarm runs:**
- The tests bind fixed ports (site 4100, browser 9333, evil 4101, web 4300), so two test runs at once collide.
- Run ONLY your task's own test file, plus `npm run typecheck`. Never run the full suite: the swarm watcher runs it at each wave gate.
- If a test fails with `CDP_PORT_IN_USE` or `EADDRINUSE`, another agent's test is running. Wait 30 seconds and run it again; do not change ports.

## Review Focus

1. **A visitor reloads mid-run.** Re-opening the event stream replays the run so far plus its latest frame, and the run still finishes. Covered by Task 4's test `a late subscriber gets the replay and the end`.
2. **Back-to-back runs.** Frames and audit events of run A must never reach run B. Covered by Task 4's test `events never leak between runs`.
3. **The spend file is corrupt or missing.** Missing means a fresh day with $0. Corrupt fails closed: the cap is reached and the recorded run plays. Covered by Task 2's test `a corrupt spend file fails closed`.
4. **A client sends its own `X-Forwarded-For`.** Only the last entry, the one Traefik appends, counts for the rate limit. Covered by Task 2's test `only the last forwarded hop counts`.
5. **Phone and Safari.** The page works at 390 px wide, and the recorded video supports byte ranges, which iOS Safari needs. Covered by Task 5's range test and Task 6's phone-viewport e2e.

```ts
import { readFileSync, writeFileSync, renameSync } from "node:fs";

/** Per-key rolling-window counter (the key is the client IP). */
export class RateLimiter {
  private hits = new Map<string, number[]>();
  constructor(private limit = 5, private windowMs = 3_600_000, private now: () => number = Date.now) {}

  /** Records the hit and returns null, or returns the whole minutes (>= 1) until a slot frees. */
  take(key: string): number | null {
    const t = this.now();
    const live = (this.hits.get(key) ?? []).filter((h) => t - h < this.windowMs);
    if (live.length >= this.limit) {
      this.hits.set(key, live);
      return Math.max(1, Math.ceil((live[0] + this.windowMs - t) / 60_000));
    }
    live.push(t);
    this.hits.set(key, live);
    return null;
  }
}

interface SpendState { day: string; usd: number }

/** Daily model spend (UTC day), kept in a small JSON file so a restart does not reset it. */
export class SpendLedger {
  private state: SpendState;
  constructor(private file: string, private capUsd = 3, private reserveUsd = 0.15, private now: () => Date = () => new Date()) {
    this.state = this.load();
  }

  private today() { return this.now().toISOString().slice(0, 10); }

  private load(): SpendState {
    let raw: string;
    try { raw = readFileSync(this.file, "utf8"); } catch { return { day: this.today(), usd: 0 }; } // missing: a fresh day
    try {
      const j = JSON.parse(raw) as Partial<SpendState>;
      if (typeof j.day === "string" && typeof j.usd === "number" && Number.isFinite(j.usd) && j.usd >= 0) return { day: j.day, usd: j.usd };
    } catch { /* corrupt: fall through */ }
    return { day: this.today(), usd: this.capUsd }; // unreadable: fail closed for today
  }

  private roll() { if (this.state.day !== this.today()) this.state = { day: this.today(), usd: 0 }; }

  spentToday(): number { this.roll(); return this.state.usd; }

  /** A run may start only if even its maximum cost cannot take the day over the cap. */
  canStart(): boolean { return this.spentToday() < this.capUsd - this.reserveUsd; }

  add(usd: number): void {
    this.roll();
    if (Number.isFinite(usd) && usd > 0) this.state.usd += usd;
    const tmp = `${this.file}.tmp`;
    writeFileSync(tmp, JSON.stringify(this.state));
    renameSync(tmp, this.file);
  }
}

/** Traefik appends the connecting client's address as the LAST X-Forwarded-For entry; earlier entries are client-supplied. */
export function clientIp(xff: string | string[] | undefined, remote: string | undefined): string {
  const header = Array.isArray(xff) ? xff.join(",") : xff ?? "";
  const last = header.split(",").map((s) => s.trim()).filter(Boolean).at(-1);
  return (last || remote || "unknown").replace(/^::ffff:/, "");
}
```

```ts
/** Free text: at most 300 characters, exactly one SYN-#### id, and at least one field the agent knows. */
export function validateFreeText(text: unknown): { ok: true; text: string } | { ok: false; message: string } {
  if (typeof text !== "string" || !text.trim()) return { ok: false, message: "Type a task, or pick one above." };
  const t = text.trim();
  if (t.length > 300) return { ok: false, message: "Keep the task under 300 characters." };
  const ids = t.match(/\bSYN-\d{4}\b/g) ?? [];
  if (ids.length !== 1) return { ok: false, message: "Name exactly one record ID, like SYN-1042." };
  const parsed = parseTask(t);
  if (!parsed.recordId || parsed.fields.length === 0) return { ok: false, message: "Ask for at least one of: claim status, balance, payer, service date." };
  return { ok: true, text: t };
}

/**
 * The real model refuses forbidden actions, so a "blocked" preset replaces the model's first `finish` with ONE scripted
 * `navigate` to show the policy layer blocking it. The page labels that step as simulated.
 */
export class SimulatingProvider implements ModelProvider {
  private done = false;
  constructor(private inner: ModelProvider, private target: string, private onSimulate: () => void) {}
  get id() { return this.inner.id; }
  get model() { return this.inner.model; }
  get mode() { return this.inner.mode; }
  async complete(req: ProviderRequest): Promise<ProviderResponse> {
    const resp = await this.inner.complete(req);
    if (!this.done && resp.toolCalls[0]?.name === "finish") {
      this.done = true;
      this.onSimulate();
      return { ...resp, toolCalls: [{ id: "sim1", name: "navigate", input: { url: this.target } }] };
    }
    return resp;
  }
}

export const simulationTarget = (kind: "write" | "offsite", siteOrigin: string) =>
  kind === "write" ? `${siteOrigin}/records/SYN-1042/delete` : "http://127.0.0.1:4101/exfil";

export function providerFor(preset: Preset | null, real: ModelProvider | null, siteOrigin: string, onSimulate: () => void): ModelProvider {
  if (!real) return new FakeProvider(preset?.fakeScript ?? "happy");
  if (preset?.simulate) return new SimulatingProvider(real, simulationTarget(preset.simulate, siteOrigin), onSimulate);
  return real;
}
```

```ts
import { randomUUID } from "node:crypto";
import type { Config } from "../../backend/src/config.js";
import type { AuditEvent, AuditStore } from "../../backend/src/audit.js";
import type { BrowserBridge } from "../../backend/src/browser/bridge.js";
import { TaskRunner, type TaskResult } from "../../backend/src/coordinator.js";
import type { ModelProvider } from "../../backend/src/providers/types.js";
import { log } from "../../backend/src/logger.js";
import { PRESETS, validateFreeText, providerFor, type Preset } from "./presets.js";
import type { RateLimiter, SpendLedger } from "./limits.js";

export type FallbackReason = "cap" | "no_key" | "browser_down" | "model_error";
export type RunEvent =
  | { type: "queued"; position: number }
  | { type: "started"; mode: "FAKE" | "REAL"; model: string; preset: string | null }
  | { type: "frame"; jpeg: string }
  | { type: "progress"; text: string }
  | { type: "audit"; event: AuditEvent }
  | { type: "simulated" }
  | { type: "result"; result: TaskResult; mutations: number }
  | { type: "fallback"; reason: FallbackReason }
  | { type: "end" };

export type SubmitResult =
  | { ok: true; runId: string; position: number }
  | { ok: false; status: 400 | 429 | 503; error: string; message: string; retryAfterMin?: number };

export interface RunManagerDeps {
  cfg: Config;
  bridge: BrowserBridge;
  audit: AuditStore;
  realProvider: ModelProvider | null; // null: no key
  allowFake: boolean; // tests and local use only
  spend: SpendLedger;
  limiter: RateLimiter;
  mutations: () => number; // the synthetic site's change counter
  maxQueue?: number; // waiting runs, default 10
  keepMs?: number; // how long a finished run's events stay for late subscribers, default 120 s
}

interface Run {
  id: string;
  preset: Preset | null;
  text: string;
  events: RunEvent[]; // everything except frames
  lastFrame: string | null;
  listeners: Set<(e: RunEvent) => void>;
  done: boolean;
}

export class RunManager {
  private runs = new Map<string, Run>();
  private queue: Run[] = [];
  private active: Run | null = null;
  constructor(private d: RunManagerDeps) {}

  presets() { return PRESETS.map(({ id, label, shows }) => ({ id, label, shows })); }
  has(id: string) { return this.runs.has(id); }

  /** Why a live run cannot start right now, or null when it can. */
  fallbackReason(): FallbackReason | null {
    if (!this.d.realProvider && !this.d.allowFake) return "no_key";
    if (!this.d.bridge.connected) return "browser_down";
    if (!this.d.spend.canStart()) return "cap";
    return null;
  }

  submit(ip: string, body: { preset?: unknown; text?: unknown }): SubmitResult {
    let preset: Preset | null = null;
    let text: string;
    if (body.preset !== undefined) {
      preset = PRESETS.find((p) => p.id === body.preset) ?? null;
      if (!preset) return { ok: false, status: 400, error: "UNKNOWN_PRESET", message: "Pick one of the listed tasks." };
      text = preset.task;
    } else {
      const v = validateFreeText(body.text);
      if (!v.ok) return { ok: false, status: 400, error: "BAD_TASK", message: v.message };
      text = v.text;
    }
    if (this.queue.length >= (this.d.maxQueue ?? 10)) return { ok: false, status: 503, error: "QUEUE_FULL", message: "The demo is busy. Try again in a minute." };
    const wait = this.d.limiter.take(ip);
    if (wait !== null) return { ok: false, status: 429, error: "RATE_LIMITED", message: `You have used your 5 runs for this hour. Try again in ${wait} min.`, retryAfterMin: wait };

    const run: Run = { id: randomUUID(), preset, text, events: [], lastFrame: null, listeners: new Set(), done: false };
    this.runs.set(run.id, run);
    const reason = this.fallbackReason();
    if (reason) {
      this.emit(run, { type: "fallback", reason });
      this.finish(run);
      return { ok: true, runId: run.id, position: 0 };
    }
    this.queue.push(run);
    this.pump();
    const position = this.active === run ? 0 : this.queue.indexOf(run) + 1;
    if (position > 0) this.emit(run, { type: "queued", position });
    return { ok: true, runId: run.id, position };
  }

  /** Replays what the run has sent so far (plus its latest frame), then streams the rest. Null for an unknown run. */
  subscribe(id: string, fn: (e: RunEvent) => void): (() => void) | null {
    const run = this.runs.get(id);
    if (!run) return null;
    const replay = [...run.events];
    const endAt = replay.findIndex((e) => e.type === "end");
    const head = endAt < 0 ? replay : replay.slice(0, endAt);
    for (const e of head) fn(e);
    if (run.lastFrame) fn({ type: "frame", jpeg: run.lastFrame });
    if (run.done) { fn({ type: "end" }); return () => {}; }
    run.listeners.add(fn);
    return () => { run.listeners.delete(fn); };
  }

  private emit(run: Run, e: RunEvent) {
    if (e.type === "frame") run.lastFrame = e.jpeg;
    else run.events.push(e);
    for (const l of run.listeners) l(e);
  }

  private finish(run: Run) {
    run.done = true;
    this.emit(run, { type: "end" });
    run.listeners.clear();
    setTimeout(() => this.runs.delete(run.id), this.d.keepMs ?? 120_000).unref();
  }

  private pump() {
    if (this.active || this.queue.length === 0) return;
    const run = this.queue.shift()!;
    this.active = run;
    this.queue.forEach((r, i) => this.emit(r, { type: "queued", position: i + 1 }));
    void this.execute(run).finally(() => {
      this.active = null;
      this.finish(run);
      this.pump();
    });
  }

  private async execute(run: Run) {
    const reason = this.fallbackReason(); // conditions may have changed while the run waited
    if (reason) { this.emit(run, { type: "fallback", reason }); return; }
    const taskId = randomUUID();
    const t0 = Date.now();
    const provider = providerFor(run.preset, this.d.realProvider, this.d.cfg.siteOrigin, () => this.emit(run, { type: "simulated" }));
    const off = this.d.audit.onEvent((ev) => { if (ev.task_id === taskId) this.emit(run, { type: "audit", event: ev }); });
    this.d.bridge.onFrame = (jpeg) => this.emit(run, { type: "frame", jpeg });
    this.emit(run, { type: "started", mode: provider.mode, model: provider.model, preset: run.preset?.id ?? null });
    try {
      const runner = new TaskRunner(this.d.cfg, provider, this.d.bridge, this.d.audit, (e) => {
        if (e.task_id === taskId) this.emit(run, { type: "progress", text: e.text });
      });
      const result = await runner.run(run.text, taskId);
      this.d.spend.add(result.usage.estimated_cost_usd);
      this.emit(run, { type: "result", result, mutations: this.d.mutations() });
      if (result.code.startsWith("PROVIDER_")) this.emit(run, { type: "fallback", reason: "model_error" });
      log("web_run", { run: run.id.slice(0, 8), preset: run.preset?.id ?? "free", status: result.status, code: result.code, usd: result.usage.estimated_cost_usd, ms: Date.now() - t0 });
    } catch {
      this.emit(run, { type: "fallback", reason: "browser_down" });
      log("web_run", { run: run.id.slice(0, 8), preset: run.preset?.id ?? "free", status: "error", code: "RUN_THREW", ms: Date.now() - t0 });
    } finally {
      off();
      this.d.bridge.onFrame = undefined;
    }
  }
}
```

```ts
import http from "node:http";
import { stat } from "node:fs/promises";
import { createReadStream } from "node:fs";
import { join } from "node:path";
import { clientIp } from "./limits.js";
import type { RunEvent, SubmitResult } from "./runs.js";

export interface RunService {
  presets(): { id: string; label: string; shows: string }[];
  submit(ip: string, body: { preset?: unknown; text?: unknown }): SubmitResult;
  subscribe(id: string, fn: (e: RunEvent) => void): (() => void) | null;
  has(id: string): boolean;
}

export interface WebServerOpts {
  service: RunService;
  publicDir: string;
  health: () => Record<string, unknown>;
  maxBodyBytes?: number;
}

export const SECURITY_HEADERS: Record<string, string> = {
  "content-security-policy": "default-src 'self'; img-src 'self' data:; media-src 'self'; style-src 'self'; script-src 'self'; connect-src 'self'; frame-ancestors 'none'; base-uri 'none'; form-action 'self'",
  "x-content-type-options": "nosniff",
  "referrer-policy": "no-referrer",
  "x-frame-options": "DENY",
};

/** The ONLY files ever served. Paths are matched exactly; nothing is resolved from the URL. */
const STATIC: Record<string, [file: string, type: string]> = {
  "/": ["index.html", "text/html; charset=utf-8"],
  "/app.js": ["app.js", "text/javascript; charset=utf-8"],
  "/app.css": ["app.css", "text/css; charset=utf-8"],
  "/recorded/run.mp4": ["recorded/run.mp4", "video/mp4"],
};

const RUN_EVENTS = /^\/api\/runs\/([0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12})\/events$/;

export function createWebServer(o: WebServerOpts): http.Server {
  const max = o.maxBodyBytes ?? 2048;

  const json = (res: http.ServerResponse, code: number, body: unknown) => {
    res.writeHead(code, { ...SECURITY_HEADERS, "content-type": "application/json", "cache-control": "no-store" });
    res.end(JSON.stringify(body));
  };

  const readBody = (req: http.IncomingMessage): Promise<string | null> => new Promise((resolve, reject) => {
    if (Number(req.headers["content-length"] ?? 0) > max) { req.resume(); return resolve(null); }
    const chunks: Buffer[] = [];
    let size = 0;
    let over = false;
    req.on("data", (c: Buffer) => { size += c.length; if (size > max) over = true; else chunks.push(c); });
    req.on("end", () => resolve(over ? null : Buffer.concat(chunks).toString("utf8")));
    req.on("error", reject);
  });

  const sendStatic = async (req: http.IncomingMessage, res: http.ServerResponse, [file, type]: [string, string]) => {
    const full = join(o.publicDir, file);
    const st = await stat(full).catch(() => null);
    if (!st) return json(res, 404, { error: "NOT_FOUND" });
    const video = type === "video/mp4";
    const m = /^bytes=(\d*)-(\d*)$/.exec(String(req.headers.range ?? ""));
    if (video && m && (m[1] || m[2])) {
      let start = m[1] ? Number(m[1]) : st.size - Number(m[2]); // "bytes=-N" is the last N bytes
      let end = m[1] && m[2] ? Math.min(Number(m[2]), st.size - 1) : st.size - 1;
      if (start < 0) start = 0;
      if (start > end || start >= st.size) { res.writeHead(416, { ...SECURITY_HEADERS, "content-range": `bytes */${st.size}` }); return res.end(); }
      res.writeHead(206, { ...SECURITY_HEADERS, "content-type": type, "accept-ranges": "bytes", "content-range": `bytes ${start}-${end}/${st.size}`, "content-length": String(end - start + 1), "cache-control": "public, max-age=3600" });
      createReadStream(full, { start, end }).pipe(res);
      return;
    }
    res.writeHead(200, { ...SECURITY_HEADERS, "content-type": type, "content-length": String(st.size), ...(video ? { "accept-ranges": "bytes" } : {}), "cache-control": file.endsWith(".html") ? "no-store" : "public, max-age=300" });
    createReadStream(full).pipe(res);
  };

  const stream = (req: http.IncomingMessage, res: http.ServerResponse, id: string) => {
    if (!o.service.has(id)) return json(res, 404, { error: "NOT_FOUND" });
    res.writeHead(200, { ...SECURITY_HEADERS, "content-type": "text/event-stream", "cache-control": "no-store", connection: "keep-alive", "x-accel-buffering": "no" });
    let ended = false;
    const heartbeat = setInterval(() => res.write(": keep-alive\n\n"), 15_000);
    let unsubscribe: (() => void) | null = null;
    const stop = () => { if (ended) return; ended = true; clearInterval(heartbeat); unsubscribe?.(); };
    req.on("close", stop); // the run continues; only this listener goes
    unsubscribe = o.service.subscribe(id, (e) => {
      if (ended) return;
      res.write(`data: ${JSON.stringify(e)}\n\n`);
      if (e.type === "end") { stop(); res.end(); }
    });
  };

  const handle = async (req: http.IncomingMessage, res: http.ServerResponse) => {
    const path = new URL(req.url ?? "/", "http://local").pathname;
    if (req.method === "GET" && Object.hasOwn(STATIC, path)) return sendStatic(req, res, STATIC[path]);
    if (req.method === "GET" && path === "/api/health") return json(res, 200, o.health());
    if (req.method === "GET" && path === "/api/presets") return json(res, 200, o.service.presets());
    if (req.method === "POST" && path === "/api/runs") {
      const raw = await readBody(req);
      if (raw === null) return json(res, 413, { error: "TOO_LARGE" });
      let body: unknown;
      try { body = JSON.parse(raw); } catch { return json(res, 400, { error: "BAD_JSON" }); }
      if (!body || typeof body !== "object" || Array.isArray(body)) return json(res, 400, { error: "BAD_JSON" });
      const r = o.service.submit(clientIp(req.headers["x-forwarded-for"], req.socket.remoteAddress), body as { preset?: unknown; text?: unknown });
      if (r.ok) return json(res, 202, { run_id: r.runId, position: r.position });
      return json(res, r.status, { error: r.error, message: r.message, ...(r.retryAfterMin ? { retry_after_min: r.retryAfterMin } : {}) });
    }
    const m = RUN_EVENTS.exec(path);
    if (req.method === "GET" && m) return stream(req, res, m[1]);
    return json(res, 404, { error: "NOT_FOUND" });
  };

  return http.createServer((req, res) => {
    handle(req, res).catch(() => {
      if (!res.headersSent) json(res, 500, { error: "INTERNAL" });
      else res.destroy();
    });
  });
}
```

```js
function listen(runId) {
  stream?.close();
  stream = new EventSource(`/api/runs/${runId}/events`);
  stream.onmessage = (m) => {
    const e = JSON.parse(m.data);
    if (e.type === "queued") $("status").textContent = e.position === 1 ? "You're next — one run at a time." : `You're number ${e.position} in line — one run at a time.`;
```

```ts
import { startSite } from "../../site/src/server.js";
import { launchDedicatedBrowser, type DedicatedBrowser } from "../../backend/src/browser/launch.js";
import { BrowserBridge } from "../../backend/src/browser/bridge.js";
import { AuditStore } from "../../backend/src/audit.js";
import { loadConfig } from "../../backend/src/config.js";
import { resolveProviderAudited } from "../../backend/src/bootstrap.js";
import { log } from "../../backend/src/logger.js";
import { RateLimiter, SpendLedger } from "./limits.js";
import { RunManager } from "./runs.js";
import { createWebServer } from "./server.js";

export interface WebAppOpts {
  port: number;
  host?: string; // default 0.0.0.0 (inside the container; Traefik is the only way in)
  spendFile: string;
  allowFake: boolean;
  env?: Record<string, string | undefined>;
  noSandbox?: boolean;
}
export interface WebApp {
  port: number;
  manager: RunManager;
  health(): { browser: "up" | "down"; mode: "REAL" | "FAKE" | "NONE"; live: boolean };
  browser(): DedicatedBrowser | null;
  close(): Promise<void>;
}

export async function startWebApp(o: WebAppOpts): Promise<WebApp> {
  const env = o.env ?? process.env;
  const key = env.ANTHROPIC_API_KEY ?? "";
  const cfg = loadConfig({ ...env, PROVIDER: key ? "anthropic" : "fake", MAX_MODEL_CALLS: env.MAX_MODEL_CALLS || "8", WALL_TIME_MS: env.WALL_TIME_MS || "90000" });
  const audit = new AuditStore();
  const realProvider = key ? resolveProviderAudited(cfg, audit) : null;
  const sitePort = Number(new URL(cfg.siteOrigin).port);
  const site = await startSite({ port: sitePort, testEndpoints: false });
  const bridge = new BrowserBridge(cfg.siteOrigin, audit);

  let browser: DedicatedBrowser | null = null;
  let restarts = 0;
  let closing = false;
  const startBrowser = async (): Promise<void> => {
    const b = await launchDedicatedBrowser({ port: cfg.cdpPort, headless: true, noSandbox: o.noSandbox, allowLoopbackPorts: [sitePort] });
    browser = b;
    await bridge.connect(b.cdpUrl, { nonce: b.nonce, userDataDir: b.userDataDir, allowPorts: b.allowPorts });
    b.proc.once("exit", () => {
      if (closing) return;
      if (restarts++ < 1) { log("browser_restart", {}); void startBrowser().catch(() => log("browser_restart_failed", {})); }
      else log("browser_down", {});
    });
  };
  await startBrowser();

  const manager = new RunManager({
    cfg, bridge, audit, realProvider, allowFake: o.allowFake,
    spend: new SpendLedger(o.spendFile), limiter: new RateLimiter(), mutations: () => site.mutations(),
  });
  const health = () => ({
    browser: (bridge.connected ? "up" : "down") as "up" | "down",
    mode: (realProvider ? "REAL" : o.allowFake ? "FAKE" : "NONE") as "REAL" | "FAKE" | "NONE",
    live: manager.fallbackReason() === null,
  });
  const server = createWebServer({ service: manager, publicDir: new URL("../public", import.meta.url).pathname, health });
  await new Promise<void>((resolve) => server.listen(o.port, o.host ?? "0.0.0.0", () => resolve()));

  return {
    port: o.port,
    manager,
    health,
    browser: () => browser,
    close: async () => {
      closing = true;
      server.closeAllConnections();
      await new Promise<void>((r) => server.close(() => r()));
      try { await bridge.close(); } catch { /* already gone */ }
      await browser?.close();
      await site.close();
    },
  };
}
```
